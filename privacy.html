Privacy Policy

Buddha-music · Last updated: 2026-11-12

Who uses this app

Buddha-music is a personal tool used only by its owner to upload videos to the owner's own YouTube channel. It is not offered to the public.

Google data the app accesses

  • youtube.upload — to upload the owner's own videos (always as private).
  • youtube.readonly — to confirm which channel is connected.

The app does not access Gmail, contacts, files, or any other Google data.

How data is stored and shared

  • The OAuth access token is stored only on the owner's own computer.
  • No data is sent to any server other than Google's YouTube API.
  • No data is sold, shared with third parties, or used for advertising.
  • The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Buddha-music's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
